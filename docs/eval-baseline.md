# 基线评测：记忆库/经验库/攻略有没有用（第 1 轮，2026-10-28）

## 设置
- 铁甲战士，进阶 5，种子 EVAL1、EVAL2、EVAL3，每个种子打两局：关记忆（off）和开记忆（on）。
- 每局都是全新的 Claude 会话，不带之前的对话；打法、工具用不用都由它自己定，不给任何提示。
- 开关：`runs/settings.json` 写 `{"memory": "off"}` 就是关记忆（开局时读取）。关记忆时：不显示本局记忆、经验、攻略，局后复盘也不显示；写经验和攻略只进日志，不改文件。
- 开记忆的局都从同一份知识快照开始（提交 `00c2828` 里的版本：8 条经验、2 篇攻略）。局后它写的新经验和攻略改动另存成补丁，再还原快照，保证三局 on 看到的东西一样。

## 记录
每局：胜负、楼层、分数、每个 Boss 前后的血量、用时、工具调用次数；开记忆的局另记它查阅了哪些经验和攻略、局后写了什么。

## 小结（第 1 轮）

- 六局全输。关记忆：F41、F33、F33（平均 37 层，424 分）；开记忆：F33、≥F45、F33（平均 ≥37 层，435 分）。差别在噪声范围内，三个种子、各一局的样本太小，**看不出经验库和攻略有没有用**。
- 两局开记忆的数据不干净：EVAL2 死于两个会话同时操作；EVAL3 被鬼魂议会的 bug 吃掉一半最大生命。
- 共同卡点是第二幕 Boss 收藏家（六局里四局死在它手上），以及第二幕普通战掉血太多、格挡不够。开记忆的局局后都写出了收藏家打法和“多拿格挡”的经验，但这些只有下一轮才会用上。
- 行为上的差别：开记忆时它每局都主动查了经验和攻略，也写了 plan/route；关记忆时没有这些。
- 接口 bug：事件给的牌（鬼魂议会）和复制者一样，是一段动画加进牌组，自动离开房间太快会丢牌。已修（事件选择后等动画结束），并加了真机场景 council_of_ghosts 待验证。

下一轮建议：先修 bug 并真机验证；把三局 on 的局后补丁合并进知识库（让经验真正累积），再用新种子各打关/开，最好每个条件 5 局以上。
